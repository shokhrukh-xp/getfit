# Проверки GetFit

Набор жил в контейнере сессии и **пропал вместе с ним 11.09**. Теперь лежит
в репозитории: контейнер одноразовый, репозиторий — нет.

## Как поднять в новом контейнере

Приложение — один файл `index.html` (в контейнере рабочая копия обычно
называется `getfit-tg.html` и лежит рядом с папкой `tg/`).

```sh
sh tg/srv.sh          # собирает site/ и поднимает сервер на 8899
node tg/test-home.js  # один набор
sh tg/run.sh          # все наборы
```

`site/` — мусорная папка, собирается заново при каждом запуске `srv.sh`.
Прогон Playwright: `node -e "require('playwright')"` должен работать;
браузер уже стоит (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`),
`playwright install` запускать не надо.

## Что внутри

- `mock.js` — общая обвязка: подменяет Telegram, фиксирует время, отвечает
  за воркер (`/day`, `/week`, `/measures`, `/circle`, `/food`, `/all`).
  **Все даты считаются от сегодняшней**: тест с захардкоженной датой
  разваливается в полночь (так и вышло 11.09 с `test-circle`).
- `test-home.js` — главная: полукруг дня, окно 06→22 и его расширение,
  пузыри в кадре, число внутри дуги, пустое утро.
- `test-bar.js` — панель записи еды: фото прикреплено → отправка → ожидание
  → ответ, и что всё это видно В САМОЙ панели.
- `shot-home.js`, `shot-bar.js` — снимки тех же состояний (`dark` / `light`),
  кладутся в `tg/*.png` (в git не попадают).
- `fixtures/` — условные «фотографии еды» для проверок.

## Грабли, которые стоили времени

- Весь скрипт приложения в IIFE: из `page.evaluate()` внутренних функций не
  видно. В тестах кликать то же, что кликает человек.
- «Сработало» ≠ «изменилось»: проверка действия обязана сравнивать состояние
  до и после.
- У новых классов — префикс: голый `.ok` однажды нарисовал зелёный блок 44 px
  на дорожке зала.
- После каждой правки — `node --check` вырезанного `<script>`: одна скобка
  гасит всё приложение.
