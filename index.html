Выбери программу — приложение спросит об этом один раз. Дни недели потом назначишь свои, кнопка «мои дни» на главном экране. Журнал тренировок будет твой личный: Telegram хранит данные каждого пользователя отдельно, чужих подходов ты не увидишь.

Каталог упражнений

Мои дни

Поставь каждому дню недели свою тренировку. Приложение само откроет нужный день и подскажет, когда следующий. У всех расписание своё — эти настройки видишь только ты.

Лёгкая неделя

Веса встали или поехали вниз? Возьми неделю с половиной подходов на тех же весах. Это единственное, чего приложение за тебя не решит — как ты себя чувствуешь, знаешь только ты. Через семь дней отключится само.

Мои данные

Нужны для одного: пока по упражнению нет истории, прикинуть, с какого веса начинать. Как только история появится, подсказки переходят на твои собственные цифры. Данные лежат только у тебя.
