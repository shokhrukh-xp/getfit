# Независимый проход 07.10

База 90935f0, ветка codex/prohod. Код приложения и BUILD не менялись.

- report.md — отчёт, копия в общей папке проекта.
- index.html — галерея снимков с полными названиями состояний.
- inventory.json — 180 состояний, элементы и геометрия.
- proofs.json — 36 адресных сценариев (включая положительный контроль подписки из чата) на mock.
- logs/matrix.json — 152 запуска сценариев действий; два отказа старого сценария перетаскивания объяснены в отчёте и перепроверены с прокруткой.
- order-scrolled-*.log — результат корректного перетаскивания.

Воспроизведение из корня worktree (Playwright должен быть доступен в NODE_PATH):

```sh
node tg/prohod-0710.js
node tg/prohod-proofs.js
node tg/prohod-matrix.js
PROHOD_WIDTH=320 PROHOD_THEME=dark node -r ./tg/prohod-preload.js tg/prohod-order.js
sh tg/run.sh --все
```

Новый HTTP-сервер для prohod-* не требуется: локальные файлы и ответы Worker перехватываются в браузере. Внешняя сеть закрыта. Цветные JPEG — тестовые изображения, не изображения живых людей. Скрипт снимков умеет повторить перечисленные через запятую состояния первым аргументом; proofs — так же.
